# 狼人杀游戏规则（屠边局，支持 6/8/9/10/12 人）

> 本文档是**唯一的规则事实来源（source of truth）**。引擎实现（`werewolf/`）和发给 agent 的
> prompt 都必须与本文档一致。任何规则变更先改本文档，再改代码。

---

## 1. 座位与身份配置

N 名玩家按 **1~N 号座位**围坐成一圈，座位号在开局时固定，死亡后座位号保留（用于"几号玩家"指代）。

支持 5 种板子，全部为屠边局：

| 人数 | 狼人 | 神职 | 平民 | 说明 |
|---|---|---|---|---|
| 6 | 2 | 预言家·女巫 | 2 | 最小可玩局，一晚定生死 |
| 8 | 2 | 预言家·女巫·猎人 | 3 | 神多民少，好人容错低 |
| 9 | 3 | 预言家·女巫·猎人 | 3 | 经典 9 人局 |
| 10 | 3 | 预言家·女巫·猎人·白痴 | 3 | 加白痴 |
| **12** | **4** | **预言家·女巫·猎人·白痴** | **4** | **标准局（默认）** |

角色代号：`WEREWOLF` / `SEER` / `WITCH` / `HUNTER` / `IDIOT` / `VILLAGER`

- **神职**：预言家、女巫、猎人、白痴（哪些神在场取决于板子）
- 身份在开局时**随机分配**（可用 `--seed` 固定，便于复现对局）

---

## 2. 胜利条件（屠边）

游戏在每次有人出局后立即结算，满足任一条件即刻结束：

| 条件 | 结果 |
|---|---|
| 狼人**全部出局** | **好人阵营胜利** |
| 神职**全部出局**（屠神） | **狼人阵营胜利** |
| 平民**全部出局**（屠民） | **狼人阵营胜利** |

> **注意**：屠边局中狼人不需要杀光所有好人。只要"神全死"或"民全死"，狼人立刻获胜。
> 这也意味着好人方在投票时需要保护"边"，而狼人会集中屠杀人数更少的一边。
>
> 可选变体 `--win-rule city`（屠城局）：狼人需要杀光**所有**好人才获胜。

### 平局与强制终止
- 若达到最大天数（默认 20 天）仍未分出胜负，判 `DRAW`（正常对局几乎不会触发，仅作为死循环保护）。

---

## 3. 角色技能详解

### 3.1 狼人 Werewolf ×4
- **夜间睁眼**：所有存活狼人互相确认身份，可在"狼人频道"内自由讨论（好人完全看不到）。
- **击杀（刀人）**：每晚可共同选择一名玩家击杀，也可以选择**空刀**（不杀任何人）。
  - 决策方式：每名存活狼人给出一个刀人意向，按票数最多者执行；
  - 平票时由**存活狼人中座位号最小者**（"狼队长"）拍板。
- 狼人**可以自刀**（刀自己的队友或自己），用于骗女巫解药等战术。
- 狼人没有验人能力，不知道好人的具体身份，只知道 4 名狼队友是谁。

#### 自爆（狼人专属）

狼人可以在**白天的发言阶段**（包括警上发言和 PK 发言）宣布**自爆**：

- 当场**亮明狼人身份**并立刻出局，身份对全场公开
- **白天立即结束**：后续所有人的发言取消，**今天不投票**，直接进入黑夜
- 自爆者**没有遗言**
- 自爆者若是警长，**警徽当场销毁**，不能移交
- 在**警上发言**阶段自爆会直接**中止整个警长竞选**，本局无警长
- 自爆只能在发言阶段进行，**投票开始后不能再自爆**

自爆的战术意义：用一条狼命换掉好人一整个白天的发言和投票。当狼队被真预言家
连续查杀、或某个白天对好人特别有利（比如预言家正要公布警徽流）时，自爆可以
打断节奏、保住队友、并且多争取一个晚上的刀。代价是场上少一只狼，所以是很贵的手段。

可用 `--no-explode` / 前端的"允许狼人自爆"开关关闭。

### 3.2 预言家 Seer ×1
- 每晚查验一名**存活**玩家，得到结果：
  - `狼人`（俗称"查杀"）
  - `好人`（俗称"金水"，包含平民与所有神职）
- 不能查验自己，不能重复查验同一人（引擎会在合法动作里过滤掉已验过的目标）。
- 首夜也可以查验。

### 3.3 女巫 Witch ×1
- 持有 **1 瓶解药**和 **1 瓶毒药**，整局各只能用 **1 次**。
- 每晚上帝会告诉女巫"今晚谁被狼人刀了"（可配置为仅首夜告知，见 §6）。
- **解药**：救活当晚被狼刀的玩家。
  - 默认规则：女巫**仅首夜可以自救**，第二夜起不能对自己使用解药。
- **毒药**：毒死任意一名存活玩家，被毒者当晚死亡。
- **同一晚不能同时使用解药和毒药**（"同一夜只能用一瓶药"）。
- 若当晚无人被刀（狼人空刀），女巫只被告知"今晚是平安夜"，解药无对象。

### 3.4 猎人 Hunter ×1
- 出局时可以**开枪**带走任意一名存活玩家（可以选择不开枪）。
- **可以开枪的情况**：被狼人刀死、被投票放逐。
- **不能开枪的情况**：被女巫毒死。**同时被刀和被毒时按"被毒"处理，不能开枪。**
- 上帝在夜晚会告知猎人当前的"开枪状态"（能否开枪），但不告知原因来源。
- 被枪杀的玩家立即出局，**没有遗言**；若被枪杀者是猎人（不可能，只有一个猎人）或白痴，按各自规则处理。
- 猎人开枪导致的死亡**会触发胜负结算**。

### 3.5 白痴 Idiot ×1
- **被投票放逐时**：当场翻开身份牌，**不死**，但从此：
  - 永久失去**投票权**（仍可发言，仍可被投票、被刀、被毒、被枪杀）
  - 失去警长身份（若是警长，警徽当场销毁）
  - 当天**不再有人出局**，直接进入黑夜
- **被狼刀 / 被毒 / 被枪杀**：正常死亡，没有翻牌机会。
- 白痴翻牌后，身份对所有人公开。

## 4. 警长（警徽流）

第一天白天开始前进行**警长竞选**，全局只选举一次。

- **1. 上警**：所有玩家同时决定是否竞选警长（`上警` / `不上警`）。
- **2. 警上发言**：所有上警玩家按座位顺序依次发言（这是"悍跳预言家"等博弈的主战场）。
- **3. 退水**：发言结束后，上警玩家可以宣布退水（退出竞选）。
- **4. 警下发言**：未上警的玩家不发言，直接进入投票。
- **5. 投票**：**未上警**的玩家投票（上警者和退水者无投票权）。
  - 票数最高者当选警长；
  - 平票 → 平票者进行一轮 PK 发言 → 未上警玩家重新投票；
  - 再次平票 → **警徽流失**（本局无警长）。
#### 警徽流（预言家的核心打法）

**警徽流**是预言家公开宣布的"接下来几晚我要验谁"的计划，通常报 2 个目标。
它的作用是**让预言家死了以后好人还知道该信谁、警徽该给谁**——12 人局里预言家
大概率活不过第二晚，没有警徽流，好人就彻底断线。

真人预言家的警上发言是固定的**三部曲**：

1. **报查验**：我是场上唯一的预言家，X 号是我的查杀 / 金水
2. **留警徽流**：今明晚连验 A 和 B
   - A、B 都是狼 → 警徽飞**外置位**（警徽流之外的人）
   - A、B 都是好人 → **撕掉警徽**
   - 一好一狼 → 警徽飞那个**好人**
3. **聊心路历程**：我昨晚为什么验 X，警徽流为什么选 A 和 B

不留警徽流的"预言家"在真人局里会被直接当成狼。**悍跳狼也必须编一份假警徽流**，
否则一眼就假；而且他第二天得把这份假警徽流圆回来。

引擎侧：
- 警徽流是发言动作里的一个字段 `badge_flow: [座位]`（最多 3 个，只能指向**存活**玩家）
- 引擎**不校验真假**，只记录"谁在第几天报了什么"，存进 `state.public_badge_flows`
- 改口是允许的（引擎不拦），但好人 agent 会把改口当成狼的证据
- 目标死了或已经验过之后从警徽流里移除，属于**履约进度**，不算改口

- **6. 警长权力**：
  - 投票权重 **1.5 票**（与普通玩家的 1 票相加计算）
  - 决定每天白天的**发言方向**（从自己左手边/右手边开始，即座位号递增或递减）
  - 出局时可以**移交警徽**给任意存活玩家，或**撕毁警徽**（此后本局无警长）

> 可用 `--no-sheriff` 关闭警长竞选，流程简化为"夜晚 → 发言 → 投票"。

## 5. 投票与放逐规则

1. 每名有投票权的存活玩家投票给一名存活玩家，或选择**弃票**。
2. 白痴翻牌后无投票权；上警者在警长选举中无投票权。
3. 警长票权 1.5，其余 1.0。
4. **最高票者出局**。
5. **平票处理**：平票玩家进入 **PK 发言**（每人一轮发言），然后由**未参与平票的玩家**重新投票。
   - 第二轮仍平票 → **平安日**，无人出局。
6. 被放逐者有**遗言**，遗言后触发猎人开枪 / 白痴翻牌。

---

## 6. 信息与遗言规则

| 场景 | 是否公布死因 | 是否有遗言 |
|---|---|---|
| 第一晚（首夜）死亡 | 否，只公布"X 号出局" | **有** |
| 第二晚起夜间死亡 | 否 | 无 |
| 被投票放逐 | 是（公开是被票出的） | **有** |
| 被猎人枪杀 | 是 | 无 |
| **狼人自爆** | **是，且公开身份** | **无** |
| 白痴翻牌 | —（不死） | —（继续发言） |

- 上帝**从不公布**死者的身份牌，也不公布死因是刀还是毒。
- 首夜若有多人死亡（狼刀 + 女巫毒），按座位号升序公布，均有遗言。

### 女巫获知刀口（可配置）
- `always`（默认）：每晚都告诉女巫今晚被刀的是谁。
- `first_night_only`：仅第一晚告知，之后女巫只能盲毒。

---

## 6.5 发言长度

每次发言（含警上发言、PK 发言、遗言）有**字数上限**，默认 **450 字**。

这个数字对标真人：中文正常语速约 220 字/分钟，牌桌上一轮发言通常给 2 分钟，
所以 450 字差不多就是一个人能说完的量。超长的发言会被引擎**判为非法并打回重说**，
而不是截断——这样 agent 会自己学会压缩重点，而不是写一篇报告然后被砍掉一半。

可用 `--max-speech-chars` / 前端的"发言字数上限"调整。

| 术语 | 含义 |

| 刀 / 刀口 | 狼人夜间击杀的目标 |
| 金水 | 预言家验出的好人 |
| 查杀 | 预言家验出的狼人 |
| 悍跳 | 狼人冒充预言家（或其他神）发言 |
| 起跳 | 玩家公开宣称自己是某个神职 |
| 打狼 | 好人身份公开指认狼人 |
| 倒钩 | 狼人假装相信真预言家，骗取信任 |
| 冲锋 | 狼人强行给好人扣帽子、带节奏 |
| 划水 | 发言无信息量、不站边 |
| 归票 | 号召大家把票投向同一目标 |
| 退水 | 放弃警长竞选 |
| 平安夜 | 当晚无人死亡 |
| 屠边 | 杀光神职或杀光平民即狼胜 |

## 8. 规则配置项总览

| 配置 | 默认值 | 说明 |
|---|---|---|
| `n_players` | `12` | 人数，可选 6 / 8 / 9 / 10 / 12 |
| `win_rule` | `edge`（屠边） | `edge` / `city`（屠城） |
| `sheriff` | `true` | 是否进行警长竞选 |
| `wolf_explode` | `true` | 是否允许狼人自爆 |
| `witch_self_rescue_first_night` | `true` | 女巫首夜可自救 |
| `witch_knows_victim` | `always` | `always` / `first_night_only` |
| `witch_same_night_both_potions` | `false` | 同夜是否可同时用解药和毒药 |
| `first_night_last_words` | `true` | 首夜死者是否有遗言 |
| `wolves_can_self_knife` | `true` | 狼人是否可以自刀 |
| `max_speech_chars` | `450` | 单次发言字数上限（≈ 真人 2 分钟） |
| `max_iterations` | `3` | 单个决策点最多向 agent 索要几次动作 |
| `max_days` | `20` | 强制终止天数 |
